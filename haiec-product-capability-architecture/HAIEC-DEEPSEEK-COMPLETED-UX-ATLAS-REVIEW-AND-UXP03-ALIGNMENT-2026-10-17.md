## 3. Important errors in *completed* mock (retain as negative tests)

1. **Unsupported seven-rung ladder** reused on Start, Estate, Case and Source Navigator; \`ladder(count)\` fills from \`i<=count\`, so a count of 0 renders one filled dot. Replace with independent capability/source/evaluation states. The existing **enforcement read-model rungDistribution** is a separately scoped canonical operational fact; do not conflate the two.
2. **Five evidence planes ≠ analyzer participation ≠ technical source freshness ≠ five assurance "levels".** Planes are REQUESTED, POLICY_AUTHORIZED, EFFECTIVELY_GRANTED, CODE_CAPABLE and OBSERVED; each per exact scoped action/source. Clicking a plane should expose plane-specific qualified evidence, not merely scan execution.
3. **No findings / no attention / 5/5 established ≠ "Clean" or "Fully evaluated".** Demonstrated in mock Invoice Agent. Selected scope and unobserved paths stay bounded; control enforcement and approved human deployment remain orthogonal.
4. **IAM JSON export/observer ≠ per-action EFFECTIVELY_GRANTED.** Mock explicitly suggests attaching export to complete that plane, which exceeds current observer. Do not auto-promote.
5. **Missing cross-system grant ≠ observed out-of-scope** without proven authoritative negative grant set; no grant = MISSING/UNKNOWN/UNVERIFIABLE. Mock falsely paints every DAI dimension red and then labels tool outside scope on missing authority.
6. **Claim "Secrets not present in source — supported" conflicts with detection** of two apparent secret patterns in comments. A zero selected live finding is bounded; cannot prove absence of secrets by allowlisted scans.
7. **Misleading catalog rules/version:** 47 rules or 20 source choices are synthetic; 176 detection rules across 31 families includes held/register-only; a registered rule does not automatically execute; a configured GitHub App/CI flow does not imply full analyzer participation. Developer copy must verify available exact active GitHub Action release, sample YAML, bearer scopes, API route, current MCP read/write eligibility before publishing; current mock's one "read-only" sentence contradicts its own \`haiec_ingest_structured\` example.
8. **Governance statement "approval ≠ deployment authorization" needs context:** approved policy vs human deployment decision vs technical execution are distinct; do not dismiss an actual scoped deployment decision as never a deployment authorization. Decisions remain gated by conditions, expiration, target enforcement.
9. **Topology graph semantic conflation:** \`qualified\` colored green for both code reachability and agent handoff; edge qualification must be typed \`observed / delegated / code-reachable / inferred\` and sourced. Do not create a whole-org identity graph from shared IDs.
10. **Source package "Full remote — complete all five evidence planes"** and static starter "ASSURANCE_EVALUATED" are unsupported unlock promises. Source-mode limits and actual evidence matter.
11. **Role simulation** in HTML merely re-renders page; not permission checks. Clickable table rows and pseudo-links must become accessible buttons/links, with focus, keyboard and touch.
12. **CSS/layout:** severe mobile AI Estate table clipping; hidden navbar/basis selector; small low-contrast text. Make responsive and preserve evidence context at 390px.
