## Standing editorial contract

1. **Preserve** canonical HAIEC identity, category **Evidence-Bound Assurance**, tagline, three pillars, six independent jobs and five separate evidence planes. Product source truth wins over prior prose.
2. **Four-word product descriptor:** Deterministic AI Action Assurance. **Universal MCP user prompt:** Run HAIEC AI Assurance (read-only preflight is performed underneath; never a credential-free scan).
3. Each new plan includes exact existing route/component/data owner, genuine buyer question, critical gaps *and already-good material*, publishable section copy, strong USP, buyer outputs, keyword/SEO owner, diagram reuse, optional user-controlled animation, both public light/dark variants, real CTA and capability claim qualification.
4. Do not create redundant architecture/diagram gallery routes. Reuse the approved Common Repo SVGs, 12-view Enterprise Architecture Explorer and previously validated assets. Existing animated homepage components are preserved.
5. True **public** dual-theme tokens and toggle must be shared across marketing pages; the existing authenticated workspace ws-* theme is not automatically applied to public pages.
6. Separate **plan committed** from **site implemented / deployed / verified**. Do not claim production page improvements based on Common Repo planning. After an authorized HAIEC implementation/merge to Main, verify auto Vercel READY and record actual commit, page URL and acceptance evidence here.
7. SEO: one primary search intent owner per canonical route, meaningful SSR content, accessible interactive enhancement, no hallucinated schema/review/rating/customer effect.
8. Synthetic teaching scenes are conspicuously labeled; real customer outcomes require exact independent evidence. A catalog item/receipt/approval does not by itself prove target-side effectiveness.
9. Enterprise commercial range/terms come from canonical commercial owners, not an independently invented product price list.
