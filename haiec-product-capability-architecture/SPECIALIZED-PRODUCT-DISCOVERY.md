## Promotion rule

Only promote an entry into the 87-row source-anchored matrix after confirming: verified handler/import call site, current producer/feature readiness, tenant-isolated authorization, commercial entitlement, evidence contract, actual UX route, qualified output, and failure/unknown behavior. Keep independent standalone products outside HAIEC core if their owner is a separate package. A source directory is not product exposure.

## Primary UX impact

Specialized tools should be discoverable through a user objective (e.g., privacy audit, policy guidance, forensic incident, credential security), but should not clutter default developer/source-assurance navigation or become mandatory prerequisites. When no provider is connected, offer a narrow evidence-collection alternative. When the capability is unavailable on the platform, label **not supported / held**, not **missing customer evidence**.
