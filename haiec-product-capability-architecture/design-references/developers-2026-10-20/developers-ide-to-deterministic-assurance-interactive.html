Developer questions

Build faster without confusing a signal for proof.

Which HAIEC integration should I start with?

Use MCP if you already work in a compatible AI coding agent. Use the GitHub App for selected remote repository scanning with fuller current source coverage, or the versioned Assurance REST API for direct integration.

Does HAIEC MCP use OAuth?

The current HAIEC MCP server uses a scoped Bearer HAIEC API key over Streamable HTTP. The key is stored securely by the client, not included in chat or version control.

Does my AI assistant decide the risk verdict?

No. The assistant may inspect allowed context and operate the workflow, while HAIEC's deterministic evaluator produces the canonical supported result and its recorded evidence basis.

Can a code scan show a useful finding before telemetry is connected?

Yes. A supported source path can identify potential consequential capability. Policy, identity, DAI and target observations strengthen distinct later questions.

Are local and CI scanners the same as full remote analysis?

No. The current local IDE and local CI options have limited preview coverage, while GitHub remote analysis is the recommended fuller-coverage source path. The analysis location and evidence pipeline remain separate.

Is a standalone AI AppSec or LLMVerify result a full HAIEC evaluation?

No. Those tools provide their own bounded findings. HAIEC Assurance uses its own authorized evaluation, qualified evidence and exact persisted result.

Do I need all five evidence planes before seeing a source finding?

No. Requested, Policy Authorized, Effectively Granted, Code Capable and Observed answer independent questions. Your first supported source finding should not be withheld while unrelated integrations are configured.

Does an evidence ingestion receipt mean my risk was closed?

It confirms the relevant intake operation, not a completed assurance evaluation. A supported new evaluation must incorporate the exact eligible source evidence to produce a further claim.

Can I automatically run runtime attacks against any endpoint?

No. Runtime testing requires an owned or explicitly authorized endpoint and per-call safety and consent. Unsupported or disallowed categories do not become permitted through an AI agent.

Where do I find exact developer results and reports?

Use the persisted evaluation ID to retrieve available summary, Agent Audit, report, Passport and PDF surfaces with the appropriate read scopes. The source links in the API reference define exact contracts.
