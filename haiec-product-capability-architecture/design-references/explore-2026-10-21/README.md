# Explore HAIEC — Interactive Platform Explorer (design reference)

Versioned copy of the approved standalone HTML source for the public
`/explore` route on `subodhkc/haiec-website`.

- `haiec-interactive-platform-explorer.html` — approved standalone design (2026-10-21)

The website implementation renders this natively (no iframe) at
`/explore`: scoped `.ex-scope` stylesheet, server-rendered sections, client
islands for the objective selector, guided/free journey walkthrough, evidence
planes, capability explorer and learning filters, plus `?goal=&step=` shareable
state.

Design intent preserved: premium light-theme editorial surface, Space
Grotesk/Inter/JetBrains Mono font mapping, grid-paper hero board, and the
seven-section narrative (objectives → action walkthrough → six capabilities →
evidence/proof → learn by doing → ecosystem → next move).
