Questions answered

Better security starts with a precise question.

Does a source finding prove an agent performed an action?

No. Source inspection can reveal supported paths and risks. An actual invocation or downstream effect needs separately qualified observation or target evidence.

Does installing the GitHub App run every scan automatically?

No. Installing and scoping the App grants access to selected repositories. Pull-request analysis and full remote Assurance are distinct workflows with their own configuration and initiation conditions.

Can I use HAIEC without a GitHub App installation?

Yes. Authenticated source analysis supports other authorized repository and upload workflows. AI AppSec is also available as an independent local developer package.

How does static security relate to runtime testing?

Static source findings address code patterns and possible action paths. Authorized runtime testing observes endpoint responses under admitted tests. Neither automatically establishes the other.

Does a standards mapping establish certification?

No. It can organize relevant technical evidence for control reviews. Certification, legal compliance and operating effectiveness have separate requirements.

What if analysis is incomplete or yields no findings?

HAIEC distinguishes findings from coverage and limitations. Unanalyzed paths and missing sources do not become evidence that the system is safe.
