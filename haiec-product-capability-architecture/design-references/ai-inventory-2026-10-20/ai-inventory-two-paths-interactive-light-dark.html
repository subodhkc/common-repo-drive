Two independent discovery paths

Different access. Different questions. Different proof.

Knowing that a provider account incurred cost does not identify a software agent. Finding an agent definition in source does not show that it ran or incurred that cost. HAIEC keeps both discoveries useful without turning one into the other.

Path 01 / Code intelligence

Discover agents from your source.

For engineering and security: Which agent definitions, tools and handlers exist, and which resource-changing paths can the implementation support?

  • Supported agent and tool definitions with source locations
  • Handoffs, teams, graph routes and MCP connection references
  • Source-qualified tool and consequence stage evidence
  • Reachable services, shared resources and unresolved paths

A defined agent is not a running instance. A reachable resource is not an observed effect.

Path 02 / Provider reporting

See provider projects, models and spend.

For AI operations and FinOps: Which connected OpenAI or Anthropic account reports consumption, and how is it attributed across projects or workspaces?

  • Authorized provider administrative credentials
  • Reported cost snapshots and period context
  • Provider, project/workspace and model where reported
  • Cost-source selection, aggregation and freshness

An admin cost report is not an agent trace, deployment inventory or proof of provider IAM grants.

Provider administrative inventory

See the provider-side usage your source code cannot show.

Connect supported OpenAI or Anthropic administrative reporting access, request organization cost records and review how model spending is attributed across provider projects and workspaces. No source-code access is required for this reporting view.

01 / CONNECT

Authorize a provider

Use the appropriate organization admin reporting credential. HAIEC stores the credential in encrypted server-side records and uses tenant-scoped access to manage the connection.

02 / COLLECT

Retrieve cost snapshots

Collect provider-reported cost data over an applicable period. Supported project, workspace, model and line-item dimensions depend on source availability.

03 / INSPECT

Review attribution and gaps

Compare reported cost by provider/project or workspace, last sync and available coverage. An unreported model, project or request remains unconfirmed.

Two reporting sources. Two different measurements.

Provider admin data: provider-reported cost snapshots. SDK instrumentation: recorded request, token and latency metrics with estimated spend when available. They may overlap and must not be added together.
