# Deterministic HAIEC Product Capability & Workflow Matrix

**Audit baseline:** 2026-10-16. **Scope:** HAIEC `Main` at `64c615f59697e9698f64638ea978edcdb28da534`; LogSense `main` at `c7491ba9124e5df72d250f1b32a4b2c77ccc2993`; manufacturing `main` at `5d2bcc9a732e4167ab15dac7bbbbf8615e4a472c`.

**Method:** Source and repository contract inspection with code anchors. No production tenant or end-to-end acceptance execution was performed. `IMPLEMENTED` means source implementation identified, **not** universal deployment readiness. `SPECIALIZED` means bounded to a producer, sector, or test. `PARTIAL` means the code explicitly limits qualification or integration. `PREVIEW`/`HELD` follow source-controlled distribution truth. `DEMO_FIXTURE` is fictional illustrative data. `PROPOSED` and `NOT_IMPLEMENTED` cannot be sold as shipped.

**Count:** 87 capability entries (HAIEC 62, LogSense 14, Manufacturing 11). This is an inspected product/convergence inventory, not a full automated every-route census. Add additional modules with exact source links rather than extrapolating.

**Source of truth:** [HAIEC](https://github.com/subodhkc/haiec-website/tree/Main), [LogSense](https://github.com/subodhkc/Enterprise-AI-Forensic-Log-Analyzer-/tree/main), [Manufacturing](https://github.com/subodhkc/manufacturing-ai-assurance-haiec/tree/main).

**Workflow independence rule:** Each capability's listed input is **local to the selected objective**. `independently_invocable=yes` means it should not require unrelated product modules; it does not remove legitimate dependencies, user authorization, source qualification, or entitlements.

**Workflow gating is an orthogonal product projection:** (1) platform readiness, (2) organization entitlement, (3) user role and permission, (4) system applicability, (5) verified integration, (6) qualified evidence, (7) approvals for mutating action. Never use billing tiers to alter assurance truth.

|---|---|---|---|---|---|
| Source developer assurance | IDE prompt / GitHub / limited local scan | Authorized repository or workspace + valid evaluation scope | IAM, monitoring, compliance | Developer, AppSec | Qualified scan + evaluated findings where supported |
