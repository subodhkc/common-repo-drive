01 / PATH FIRST

Find the consequential path

Untrusted content may influence a model. A meaningful security review follows whether that influence can reach a privileged operation, and what separate evidence would establish execution or effect.

First prove the code path

A source analyzer may establish a reachable function or a bounded candidate mapping. Neither is automatically a runtime exploit.

Then qualify business authority

IAM credentials, approved policy, delegated choice and actual guard enforcement are separate facts. Their coverage can differ in scope, version, actor and time.

Security conclusion rule

A raw scanner match is not automatically a qualified vulnerability. A qualified code-capable path is not automatically an exploited path. A tool invocation is not independently verified business impact.

Agent Audit report vocabulary

Established: Source-qualified claim for exact scope. Unestablished: A meaningful question the evidence cannot answer. Not assessed: No eligible source/analysis for that dimension. Limitation: Coverage, version, identity or causal gap explicitly retained.
