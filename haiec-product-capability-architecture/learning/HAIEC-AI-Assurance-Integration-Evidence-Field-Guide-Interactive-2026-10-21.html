COMMON IMPLEMENTATION QUESTIONS

Before you connect another system.

Must we connect GitHub before we can evaluate anything?

No. HAIEC has separate authorized onboarding paths for connected source, local source, runtime-only inputs and declared artifacts. Each supports different claims, and unverified declarations remain declarations.

Does AWS IAM prove which actions are effectively granted?

Not in the current general case. The AWS observation is partial because resource, session, endpoint and other authorization layers may be missing. Keep effective-grant claims bounded until those layers are qualified.

Does OTLP telemetry tell us whether the target changed?

No. A trace, metric or log can provide observation evidence. An external business target effect needs independently qualified target-side or equivalent evidence.

Can ServiceNow records serve as human approval evidence?

They may provide context or eligible records when authorized, but the specific approved decision, scope, person and version still need verification. A ticket acknowledgment is not automatically authorization.

Is MCP itself an evidence source?

MCP is an assistant integration and action interface. A qualified tool response may lead to source evidence, but tool discovery or an agent-generated explanation does not establish a customer-side permission, action or target effect.

Can HAIEC use source findings if no runtime integration exists?

Yes, when the source analysis and its scope qualify, code-capable action paths can be meaningful initial findings. Runtime behavior, deployed permission and target outcome must remain unestablished if not independently supported.

Does connection success mean our AI is approved to deploy?

No. Connection, data intake, assurance result, human deployment decision and native enforcement are different actions and evidence classes.

Where do we confirm the actual available tools for our account?

Check the current authenticated HAIEC integration interface and scoped preflight. Availability depends on your tenant, credentials, configured sources, permissions, and the tool registry. This offline guide makes no live checks.
