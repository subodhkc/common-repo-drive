## 3. Four P2 findings for backlog/very small future owner-correctness pass

**P07-R01 — 'analyzers' versus persisted *execution components*.** UI heading `Which analyzers actually participated` and `{N} executed` count all persisted AEI `components` including kinds `RULE_PACK`, `REMOTE_SCANNER`, `SCAN_ENGINE`, `SEMANTIC_WORKSPACE`, `SEMANTIC_SIDECAR`. This is a real semantic risk if interpreted as N unique executable analyzers/rules. Canonical `AnalyzerExecutionIdentity` is a *component* identity model. Rename the headline/count to **execution components** or otherwise explicitly distinguish grouping, not a universal analyzer tally. Do not change the persisted record, infer an analyzer denominator or group unrelated artifact kinds as actual executions. P2, not a broken engine.

**P07-R02 — scoped response identity and context-switch lifecycle.** `loadSeq` increments when `load()` executes inside an effect. It prevents older responses after a newer `load()` is initiated, but there is **no check that returned `res.evaluationId` / `res.bundle.evaluationIdentity.evaluationId` equals current route ID before `setData(res)`**; and `data` is not cleared in `load()` when route/org context changes. A brief stale display during React org/context transitions is *plausible*, not independently reproduced. Existing `tests/unit/uxp07-evaluation-results.test.ts` only statically assert `loadSeq` snippets, **not a behavioral race**. Consider exact response-ID guard, mounted/organization-context cancellation and immediate stale-bundle suppression keyed by route+authorized organization if this page is next touched. Test delayed A/B responses and same route/different org behavior without suggesting a known cross-tenant API bypass. Do not create new report backend.

**P07-R03 — scan-backed does not necessarily mean a full static *repository* analysis.** Both the identity strip and provenance header map `evaluationBasis==='SCAN_BACKED'` to `Static repository scan`. But the canonical bundle `evaluationBasis` is only `SCAN_BACKED|EVIDENCE_ONLY`; **source mode is a separate fact**. Prefer **`Scan-backed evaluation`** and, if actual qualified source mode is available in the same frozen bundle, render it separately. Additionally, missing `exactScanId` shows `no bound static scan — evidence-only evaluation` in the provenance header **even when `evaluationBasis` is SCAN_BACKED or absent historical**; qualify that as *exact static scan ID unavailable*, not proof of evidence-only. Avoid fictitious FULL_REPO_SCAN from local bundle.

**P07-R04 — unknown synthetic classification not surfaced in new first viewport.** Banner only when `syntheticClassification==='SYNTHETIC_REFERENCE'`. Contract allows `NONE|SYNTHETIC_REFERENCE|UNKNOWN` and undefined legacy, which are not equivalent; don't silently imply production truth for unknown/legacy. Add compact classification status only if useful in next owned report refresh. True synthetic reference records remain marked.

**Work-order decision:** no source-confirmed critical security or evidence corruption requiring a P07.1 sprint; P07 UI is additive and deployed. Track P2 as isolated correction. If a reproducible selected-eval/org stale cross-display is found with authorized fixtures, escalate and fix narrowly; otherwise **proceed UX-P08 now**.
